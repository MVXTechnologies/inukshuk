# Inukshuk — logo monochrome (merch / impression)

Tons « Stone & Paper » de l'app :

- **Brun-gris** `#3B352E` — pour tissus pâles
- **Crème** `#F1E8D4` — pour tissus foncés

| Fichier | Usage |
|---|---|
| `inukshuk-logo-brun.svg` / `-creme.svg` | Symbole + texte INUKSHUK en dessous (vectoriel, pour l'imprimeur) |
| `inukshuk-logo-*-print.png` | Même chose en PNG haute résolution (×6) |
| `inukshuk-mark-*.svg` / `-print.png` | Symbole seul |
| `apercu-tshirts-avec-nom.png` | Aperçu sur chandails, avec le nom |
| `apercu-tshirts-symbole.png` | Aperçu sur chandails, symbole seul |
| `apercu-tshirts.png`, `preview.html` | Planche de test complète (couleurs, zoom des contours) |

Le logo couleur officiel de l'app reste `assets/icon.png` (pierres réalistes).
