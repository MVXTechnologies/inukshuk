# Test fixtures

- `openbeta_quebec_sample.json`: rows of the OpenBeta weekly export
  (v2026-10-04, CC0) for Lac Long, Weir, Val-Bélair and the Portneuf ice
  area. The columns the pipeline reads only (no descriptions, no first
  ascents).
- `osm_weir.json`: the Overpass answer of `osm_fetch.query_for` for the Weir
  box `[-74.54, 45.94, -74.52, 45.95]`, 2026-10-05. © OpenStreetMap
  contributors, ODbL 1.0.
- `c2c_waypoint.json`: a made-up camptocamp waypoint in the API's shape
  (invented text and numbers), so no CC BY-SA text is copied here.
