# Inukshuk vector logo

Reconstructed from the original landscape, using the clean geometric inukshuk from the
provided revamp reference.

The central stones have restrained angular outlines with small, uneven bevels. Their
dark-granite grain is deliberately faint, using unique, irregular mineral shapes at
25% opacity without repeating tiles or periodic modulation. All details are editable
vector paths clipped to the individual stones.

- `inukshuk-logo.svg` — main logo with rounded corners and a transparent exterior.
- `inukshuk-logo.png` — 1024 × 1024 preview of the main logo.
- `inukshuk-logo-square.svg` — artwork extending to every edge of the square.
- `inukshuk-logo-square.png` — 1024 × 1024 export of the square artwork.
- `inukshuk-background.svg` — landscape alone, without the central symbol.
- `inukshuk-mark.svg` — the charcoal symbol alone, on a transparent background.

The landscape uses a 1254 × 1254 SVG viewBox. All artwork consists of editable vector
paths and rectangles, with named groups for terrain, contour lines, river, mountains,
and the inukshuk. The SVGs contain no embedded raster images, fonts, filters, or external
dependencies.
