NO ACCOUNT, NO LOGIN, NO UGC, NO PAID CONTENT. Every feature works on a fresh install; no demo credentials or sample files are needed.

PURPOSE: offline trail navigation for hikers, skiers, snowshoers, paddlers and hunters. Renders official georeferenced PDF topo maps (imported, or downloaded free in-app from USGS / Natural Resources Canada / Geoscience Australia) with the GPS position drawn on top, fully offline; records outings as GPX with elevation profile, notes and 3D terrain. Free, open source (MIT), no ads, no analytics, no tracking.

HOW TO SEE IT: Search tab -> "Around you" lists free topo sheets near the device (US/Canada/Australia; elsewhere search a name, e.g. "Denver") -> Download -> it renders on the Map. Record: Map -> "+" -> Record track -> pick activity -> Start; Stop saves to the Library. Library -> tap a trail -> 2D/3D view, elevation profile, notes. Offline: Map -> "+" -> Download map area.

BACKGROUND LOCATION (UIBackgroundModes: location): used only to keep a recording the user explicitly started running when the screen locks or the app is backgrounded. Starts on "Start recording", stops on Stop. Works with "While Using" permission too.

EXTERNAL SERVICES (all direct HTTPS from the device; no backend, no identity sent): OpenStreetMap tiles; Esri/ArcGIS Online (Satellite, Relief); AWS Terrain Tiles (elevation); OpenFreeMap (labels); Waymarked Trails (optional overlay); OSM Nominatim + Apple geocoder (place names); our static catalogue at inukshuk.mvxtechnologies.com with sheet downloads from USGS, NRCan, Geoscience Australia; Expo EAS Update (OTA JS); GitHub Issues (optional automatic error reports: message, stack, app/OS version, device model; no location or content; off in Settings -> System settings -> Privacy). Weather, marine charts and Strava exist in code but are DISABLED in this release and unreachable from the UI. No AI, payments or auth providers.

REGIONS: identical behaviour everywhere; only the free-sheet catalogue coverage differs (US/CA/AU). Nothing is geo-restricted.

REGULATED / PROTECTED MATERIAL: none. All map data is open-licensed and attributed in Settings -> System info -> "Maps & data" (OSM ODbL, Esri terms, AWS open data, USGS public domain, NRCan OGL-Canada 2.0, GA CC-BY 4.0). We link to the agencies own downloads; nothing is rehosted.

LOCAL NETWORKING: during an offline-region download a short-lived HTTP server on 127.0.0.1 serves the style document to the map engine; torn down afterwards, never exposed off-device.
